### `src/multiagent_elbo/finite/closure_residual.py`

Four defects in the coarse measurement, all of which moved published numbers.

Divergence tables are indexed `[receiver_state, source_state]` but were broadcast by
`reshape`, which fills axes in ascending order, so on any edge whose receiver had the
higher agent index the row axis landed on the source. The child weight tensor construction
is now factored out as `_coarse_child_weights` and transposes the table before broadcasting
when the receiver occupies the later axis.

The `kappa_belief` and `kappa_model` factors that `tower_vfe` and `partition_dynamics`
apply to the same edge-event law were missing; both `_block_action` and the coarse path now
apply them.

The parent measure was hard-coded uniform. Added `_declared_parent_prior`, which reads
`PARENT_STATE_WEIGHTS` from `tower_vfe`, and both directions now use it.

The blocking kernel was normalized over children rather than parents, so it did not
preserve the partition function. Each block's operand is now the full Bayes posterior
$T(p \mid x_B)$ under the declared parent law, normalized over parents, contracted as one
operand per block rather than one per agent.

`flow_weighted_residual` now centers the omitted part on its own flow mean, as it already
did for the retained part.

`coarse_closure_residual` now validates that the partition arranges every declared agent
exactly once, and raises a named `ValueError` rather than a bare `StopIteration` when no
declared candidate carries three blocks.

Module and function docstrings rewritten: they had described the retired direction as
primary, called the contraction weight "the exact block configuration law of the declared
model" when it was not, and omitted that the fine object being blocked is the auxiliary
pairwise child theory rather than the declared generative tower.

### `src/multiagent_elbo/finite/mark_carrying_parent.py`

`regauge` applied one uniform shift to every boundary leg, but the induced gauge action
moves the two orientations oppositely: with a block-constant gauge $h_v = g$, a leg whose
receiver is inside transforms as $V' = V - g$ and one whose source is inside as
$V' = V + g$. The shift is now selected by an orientation test. The presentation was pushed
by $\rho(+\text{shift})$; the compensating matter rule $z'_v = \rho(-h_v) z_v$ makes it
$\rho(-\text{shift})$, confirmed by regauging the model and comparing
`_unrestricted_cost_table`, which agrees to $0.0$ exactly at $-1$ and deviates by $1.98$ at
$+1$. Every root-frame object now moves by $-g$, one consistent action, so the root-gauge
orbit is an orbit of the gauge action rather than of a different group.

The test that claimed to pin this regauged with `regauge` on both sides and never
recomputed `mark_datum`, so it could not fail. Replaced with four tests that rebuild the
model from regauged elements and recompute the datum from scratch, covering both leg
orientations, all four legs of a bi-directed block, the presentation equivariance, and
orbit-representative invariance across the true orbit. All four fail against the pre-fix
code.

### `src/multiagent_elbo/finite/two_channel_gauge.py`

`walk_element` computed a backward traversal as $-\Theta_e$, which writes the reciprocity
hypothesis into the primitive, so an independent-convention instance silently used negated
forward elements instead of its declared reverse arcs. Added `declared_reverse_arcs`; a
backward step now reads the declared reverse arc when one exists and falls back to
$-\Theta_e$ only otherwise. The reference skeleton declares no reciprocal pair, so the new
branch is unreachable there: the concatenated `downward_kernel` over every measurable
candidate block hashes identically before and after, and holonomy groups and tree
transports are unchanged at all six roots in both channels. That invariance is now pinned
by a test, because the closure measurements depend on it.

### `src/multiagent_elbo/finite/bidirected.py`

`basis_loops` built its cycle basis on the underlying undirected graph, so no two-cycle was
ever a face — precisely where the independent convention's curvature lives, which the
module docstring calls its substantive content. The face set now carries one two-cycle per
reciprocal pair plus the tree fundamental loops, eleven in total, and the arc-incidence
matrix has rank eleven, matching $|E| - |V| + 1$. Reciprocal two-cycles are identically
flat, so reciprocal results keep their content.

The two conventions were not matched controls: the reverse-element draws advanced the
shared generator, so the independent branch got different attention rows. Reverse elements
now draw from a separate stream, leaving the reciprocal instance unchanged and putting both
conventions on the same rows and forward elements.

`wilson_action` summed both orientations of each geometric two-cell, charging it twice at a
different normalization from the identically named function in `plaquette_action`. Now
averaged, which halves the reciprocal-instance value exactly — the arithmetic signature
that the added two-cycles contribute zero under reciprocity.

`reversal_is_inverse` keyed faces by sorted vertex set, which merges distinct loops sharing
a vertex set, and reported a missing reverse arc as a reciprocity violation. Now keyed by
edge-index multiset, and a missing orientation raises rather than reading as a refutation.

### `src/multiagent_elbo/finite/plaquette_action.py`

`wilson_defect` keeps its semantics, so no published number moves, but the docstring now
says what it is: the $Z_n$ flatness indicator, agreeing with $1 - \mathrm{Re}\,\chi$ up to
scale only at $n = 3$. Added an `is_faithful` guard, since an unfaithful representation
would make real curvature invisible to the action. The module docstring's claim that the
plaquette weights are built from receiver occupancies was false — they are built from the
declared rows alone — and the invariance argument now rests on the rows being independent
of the connection, noting that connection-dependent attention would need its own proof.
